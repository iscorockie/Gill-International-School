## About this build

The entire website is a **single self‑contained `index.html`** — all CSS, JavaScript, the school logo and every photograph are inlined (images as base64 data URIs). There are **no build steps, no frameworks and no dependencies**, so it can be hosted anywhere: GitHub Pages, any shared host, or even opened directly from disk.

The only optional external references are Google Fonts (falls back to system fonts) and an OpenStreetMap embed for the contact map.

## Deploying (GitHub Pages)

1. Upload `index.html` to the root of a repository (this repo already has it on `main`).
2. **Settings → Pages → Source:** *Deploy from a branch* → `main` / `/ (root)`.
3. The site publishes automatically at `https://<username>.github.io/<repo>/` within a minute of each push.

To update the site, simply replace `index.html` and push — no rebuild required.
